# 快速开始

十分钟内组装一个 agent，并写掉你的第一个 hook。

## 安装

```bash
go get github.com/xuanlv2002/ezloop
```

要求 Go 1.25+。引擎框架层零第三方依赖；接真实模型需要一个 provider（`ext/provider/openai` 是 OpenAI 兼容的参考实现，也可以自己实现 `provider.ModelProvider`，接口只有一个 `Invoke`）。

## 第一个 agent

```go
package main

import (
    "context"
    "os"

    "github.com/xuanlv2002/ezloop/core"
    "github.com/xuanlv2002/ezloop/ext/provider/openai"
)

func main() {
    p := openai.New(openai.Options{
        BaseURL: "https://api.siliconflow.cn/v1", // 任意 OpenAI 兼容服务
        APIKey:  os.Getenv("OPENAI_API_KEY"),
        Model:   "deepseek-ai/DeepSeek-V3.2",
    })

    agent := core.NewAgent(p,
        core.WithSystemPrompt("你是一个严谨的助手。"),
        core.WithHooks(auditLog{}), // 下一节写的 hook
    )

    state, err := agent.Run(context.Background(), "介绍一下你自己")
    if err != nil {
        panic(err)
    }
    _ = state.Messages // 完整历史，最后一条 assistant 是最终答复
}
```

`Run` 驱动「模型 → 工具 → 模型」循环：模型发起工具调用，引擎执行并把结果写回历史，模型继续，直到它给出不含工具调用的答复。

## 写你的第一个 hook

hook 是普通 struct：实现 `Name()`，再实现你关心的小接口。这个把每次工具调用记进日志的 hook 只要 8 行：

```go
type auditLog struct{}

func (auditLog) Name() string { return "audit" }

func (auditLog) OnToolStart(_ context.Context, _ *types.LoopState, call *types.ToolCall) (hook.Action, error) {
    log.Printf("tool %s %s", call.Name, call.Args)
    return hook.Proceed, nil
}
```

返回 `hook.Skip("理由")` 的话这次调用就不执行、理由作为工具结果回传模型——一个审批 hook 的核心就这么多。全部时机点与契约见 [Hook](Hook.md)。

再进一步，给模型一个自己写的工具（schema 从参数结构体反射生成，不用手写 JSON）：

```go
nowTool := types.NewTool("now", "返回当前时间", func(_ context.Context, in *struct{}) (string, error) {
    return time.Now().Format(time.RFC3339), nil
})

agent := core.NewAgent(p, core.WithTools(nowTool), core.WithHooks(auditLog{}))
```

## 多轮对话

上一轮的 `Messages` 原样传回来即可，没有需要维护的会话对象：

```go
state, _ := agent.Run(ctx, "帮我查一下现在几点")

state, _ = agent.Run(ctx, "那 10 分钟前呢",
    core.WithHistory(state.Messages...))
```

`WithHistory` 自动过滤历史里的 system 消息——system 是 agent 的属性，每轮由引擎重新注入，全程只有一条。会话存盘与恢复也一样：把 Messages 写进你的存储，下次 `WithHistory` 传回来就是恢复。自己封装一个持久化 hook（EndHook 里落盘）通常是每个项目最先写的第二个 hook。

## 流式输出与事件

```go
agent := core.NewAgent(p, /* … */, core.WithStreaming(true))

h := agent.RunAsync(ctx, "长任务")
defer h.Cancel() // 取消只影响这一次 Run
for e := range h.Events() {
    switch e.Type {
    case event.EventModelChunk: // 正文增量
        fmt.Print(e.Data.(string))
    case event.EventToolStart:  // 工具开始（e.Data 是 *types.ToolCall）
        fmt.Printf("\n🔧 %s", e.Data.(*types.ToolCall).Name)
    }
}
state, err := h.Wait()
```

事件通道在 loop 结束时自动 close。所有事件带 `ForkID` 字段区分主循环与分身。
